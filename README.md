# StoryNook

StoryNook is a mobile app designed to help readers keep track of the books they have read, monitor their current reading progress, save recommendations, set reading goals, and discover new books based on real reader opinions rather than social-media-style algorithms.

## Overview

StoryNook acts as a personal reading journal and book tracker that fits around real-life reading habits. It is built for readers who do not always read in a consistent pattern, while still helping them stay organised, motivated, and engaged with the books they love.

The app includes structured reviews to improve recommendation quality and helps users discover books in a more thoughtful and meaningful way. It can also be used with friends to share books, discuss reading experiences, and connect in private reading circles.

## Key Features

- Track books you have read
- Monitor your current reading progress
- Save and revisit recommended books
- Set personal reading goals
- Discover new books based on reader opinions
- Write structured reviews
- Join private reading circles with friends
- Enjoy a more social and user-focused reading experience

## Why StoryNook?

Many readers want more than a simple book list. StoryNook is designed with the user in mind, focusing on:

- personal organisation
- meaningful recommendations
- motivation to read consistently
- social interaction without algorithm-driven pressure

## Mission

To make reading more social, intentional, and enjoyable by giving readers a space to track, reflect on, and share their reading journey.

## Future Goals

- Expand reading analytics and progress insights
- Improve recommendation matching through user reviews
- Add friend and group reading features
- Create a more engaging and intuitive mobile experience
